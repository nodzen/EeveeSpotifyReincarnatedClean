EeveeSpotify Version Update Locations
=====================================

When bumping the version, update these 3 files:

1. control
   - Line 3: Version: X.X.X
   - Example: Version: 6.4.5
   - Single source of truth: the Makefile parses it into
     GeneratedConfig.version, which Tweak.x.swift uses at runtime.

2. README.md
   - Update the `Release:` badge in the header
   - Example: **Release:** `6.4.5`

3. .github/workflows/builddeb.yml
   - Update the `tag` input `default` (e.g. "v6.7.3")

`build-ipa-local.sh` reads the IPA version automatically from `control`; no separate edit is needed.

These values must match for consistent versioning across:
- .deb packages (control)
- Tweak runtime (GeneratedConfig.version, generated from control by the Makefile)
- IPA builds (build-ipa-local.sh)

Spotify Version -> Hook Target Map
===================================
(Sources/EeveeSpotify/Tweak.x.swift `hookTarget`, cases in
 Sources/EeveeSpotify/Shared/Models/VersionHookTarget.swift)

- 8.9.8  -> .lastAvailableiOS14  (last Spotify for iOS 14)
- 9.0.48 -> .lastAvailableiOS15  (last Spotify for iOS 15)
- 9.1.x  -> .v91                 (current family, guarded per-build)
- else   -> .latest              (older/newer, modern hook set)

Init flow: init() -> configureCommon() (all versions),
then .v91 -> configureV91() | otherwise -> configurePre91AndLatest().
Rule: match raw version strings only inside `hookTarget`.
